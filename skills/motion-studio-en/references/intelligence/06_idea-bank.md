# Idea bank (one-line concepts)

Use for "surprise me", to break the sameness and to propose 2 or 3 concepts to the user. Format: **concept** → bridge element → strong moment. Markers: `[G]` comes from a real gallery video (reinterpreted); `[N]` is a new idea in the same spirit. Always adapt to the user's brand/subject. For each chosen concept you still need the full brief (`../playbook.md`).

## Hook ideas (first 1.5 s)

70. A question in giant type that the first action answers.
71. The through-line object already moving, framed off-center, that lands in the center on beat 2.
72. An impossible number that corrects itself ("1,000,000" → "1", which is what matters).
73. A hard cut on a strong beat onto a flat-color frame.
74. A word that appears letter by letter and ends unexpectedly.
75. A line drawing the object's outline before it exists.

## Ending ideas (last 2 s)

76. The through-line object becomes the logo; the name rises from a mask.
77. The first frame returns (loop), with a new detail.
78. A contraction of everything into a dot, and the dot becomes the full stop of the promise sentence.
79. A card with one action only: name + one line + URL.
80. A discreet "thank you/to be continued", never a double CTA.

## To break the sameness (vary one axis)

81. Font: italic serif instead of sans; condensed display for sport; mono for dev.
82. Color: an accent outside orange/blue (acid green, hot pink, ochre).
83. Structure: no cursor; no UI; only typography and shape.
84. Camera: continuous vertical; floor plan (seen from above); a lateral tracking shot.
85. Material: paper, fabric, clay, oscilloscope, blueprint, risograph, newspaper.
86. Time: slow the hook (2 s) and speed up the middle; a rhythm contrast.
87. Scale: everything in close-up, pull back only once.
88. Sound: no music, only foley.
89. Text: only verbs; only numbers; a single word per scene.
90. Final state: a frame with everything in order after the chaos (CHAOS → CONTROL → CLARITY → BRAND).
