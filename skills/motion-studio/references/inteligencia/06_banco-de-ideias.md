# Banco de ideias (conceitos de uma linha)

Use para "me surpreenda", para quebrar a mesmice e para propor 2 ou 3 conceitos ao usuário. Formato: **conceito** → elemento-ponte → momento forte. Marcação: `[G]` vem de um vídeo real da galeria (reinterpretado); `[N]` é ideia nova no mesmo espírito. Sempre adapte à marca/ao assunto do usuário. Para cada conceito escolhido, ainda é preciso o brief completo (`../playbook.md`).

## Para quebrar a mesmice (varie um eixo)

81. Fonte: serifa itálica no lugar da sans; display condensada para esporte; mono para dev.
82. Cor: acento fora do laranja/azul (verde-ácido, rosa choque, ocre).
83. Estrutura: sem cursor; sem UI; só tipografia e forma.
84. Câmera: vertical contínuo; planta baixa (visto de cima); travelling lateral.
85. Material: papel, tecido, massinha, osciloscópio, blueprint, risograph, jornal.
86. Tempo: ralentar o hook (2 s) e acelerar o meio; contraste de ritmo.
87. Escala: tudo em close, uma única vez recuar.
88. Som: sem música, só foley.
89. Texto: apenas verbos; apenas números; uma só palavra por cena.
90. Estado final: um quadro com tudo em ordem após o caos (CAOS → CONTROLE → CLAREZA → MARCA).
