# Banco de ideas (conceptos de una línea)

Úsalo para "sorpréndeme", para romper la igualdad y para proponer 2 o 3 conceptos al usuario. Formato: **concepto** → elemento puente → momento fuerte. Marcas: `[G]` viene de un video real de la galería (reinterpretado); `[N]` es una idea nueva en el mismo espíritu. Adáptalo siempre a la marca/al tema del usuario. Para cada concepto elegido aún hace falta el brief completo (`../playbook.md`).

## Para romper la igualdad (varía un eje)

81. Fuente: serif cursiva en lugar de sans; display condensada para deporte; mono para dev.
82. Color: un acento fuera del naranja/azul (verde ácido, rosa fucsia, ocre).
83. Estructura: sin cursor; sin UI; solo tipografía y forma.
84. Cámara: vertical continua; plano cenital (visto desde arriba); un travelling lateral.
85. Material: papel, tela, plastilina, osciloscopio, blueprint, risograph, periódico.
86. Tiempo: ralentiza el gancho (2 s) y acelera el medio; un contraste de ritmo.
87. Escala: todo en primer plano, retroceder solo una vez.
88. Sonido: sin música, solo foley.
89. Texto: solo verbos; solo números; una sola palabra por escena.
90. Estado final: un cuadro con todo en orden tras el caos (CAOS → CONTROL → CLARIDAD → MARCA).
